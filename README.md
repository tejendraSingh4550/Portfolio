# Tejendrapal Singh Nathawat — Portfolio

A responsive React portfolio built from the details in the supplied resume.

## Sections
- Hero / professional headline
- Profile summary
- Work experience and training
- Technical skills
- Expandable project details
- Education
- Contact information
- Dark / light theme toggle
- Responsive mobile navigation and section animations

## Run locally
Requirements: Node.js 18+ (Node.js 20+ recommended) and npm.

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```
